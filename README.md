# 산업연관표 분석 웹앱 (2023년 산업연관표 연장표)

한국은행 「2023년 산업연관표(연장표)」의 **기본부문(380)·통합소분류(165)·통합중분류(83)·통합대분류(33)** 투입산출표를
방문자의 브라우저에서 Python(Pyodide)으로 읽어 산업연관분석을 수행하는 GitHub Pages 정적 웹앱입니다.
별도의 Python 서버가 필요 없습니다.

- **게시 주소: https://injung1412-hash.github.io/ji_2994/**
- 자료 기준: 2023년, **생산자가격**, 당해년 가격, 금액 단위 **백만원**

## 2. 사용 방법

1. 게시된 주소에 접속합니다.
2. **투입산출표 불러오기**에서 `기본부문`·`통합소분류`·`통합중분류`·`통합대분류` 카드 중 하나를 누르거나 `4개 분류 모두 불러오기`를 누릅니다. 각 화면의 안내 상자에 있는 불러오기 버튼을 눌러도 됩니다.
   - 첫 실행 때 Pyodide(Python)·numpy·openpyxl을 내려받느라 10~30초, 기본부문(12.3MB) 읽기에 추가 시간이 걸립니다. 전체 로딩은 보통 1분 안팎입니다.
   - 불러오는 즉시 원표의 계수 시트와 앱의 재계산 결과를 대조하며, 결과가 상태 표시줄과 ⑩ 검증 탭에 나옵니다.
3. 왼쪽 사이드바의 **분석 기준 분류**(기본부문·소분류·중분류·대분류)를 고르고, 아래 메뉴(자료 / 구조 분석 / 파급효과 분석 / 검증·방법)에서 화면을 고릅니다. 부문 선택 칸 위의 검색창에 이름이나 코드를 입력하면 목록이 좁혀집니다. 첫 화면의 투입산출표 구조도는 자료를 불러오면 원표로 다시 계산한 금액으로 바뀝니다.
4. **취업·고용유발**은 통합대분류를 함께 불러와야 계산됩니다(통계표의 대분류 취업자 수 사용).
5. 표의 열 제목을 누르면 정렬되고, `CSV 다운로드`로 결과를 내려받을 수 있습니다(엑셀에서 한글이 깨지지 않도록 UTF-8 BOM 포함).
6. 선택: `같은 한국은행 양식의 다른 엑셀 파일 직접 올리기`로 ECOS에서 받은 같은 양식의 투입산출표를 올려 분석할 수 있습니다. 파일은 브라우저 안에서만 처리됩니다.

### 분석 예시
- **반도체 수출 1조원 감소의 파급효과**: ⑦ 탭 → `예시: 반도체 수출 1조원 감소` → `파급효과 계산`
  - 통합대분류 기준: 생산 −1조 7,181억원(생산유발 배수 1.718), 부가가치 −5,716억원, 수입 −4,284억원, 취업 −3,622명
- **원유 수입가격 10% 상승**: ⑧ 탭(기본부문) → 수입품 가격 상승, 부문 `0621 원유`, 10% → 나프타 7.5%, 제트유 7.4%, 경유 6.7% 상승, 소비자물가 영향 약 0.21%
- **집계 편의**: ⑨ 탭 → `3102 집적회로`, 1조원 → 생산유발액이 기본부문 1조 5,084억원, 통합대분류(컴퓨터·전자 및 광학기기) 1조 7,181억원으로 13.9% 차이

## 4. 분석 방법(산식)

한국은행 「주요 용어 해설」과 통계표 각주의 산식을 그대로 따릅니다.

- **투입계수**: a<sub>ij</sub> = z<sub>ij</sub>/x<sub>j</sub>, 국산 a<sup>d</sup><sub>ij</sub> = z<sup>d</sup><sub>ij</sub>/x<sub>j</sub>, 수입 a<sup>m</sup><sub>ij</sub> = z<sup>m</sup><sub>ij</sub>/x<sub>j</sub>
  (산출액이 0인 부문 — 기본부문 천연고무·유연탄·원유·천연가스·원당, 소분류 원유 및 천연가스 — 의 계수는 0)
- **생산유발계수**: L = (I − A<sup>d</sup>)<sup>−1</sup> (비경쟁수입형). 부문별 생산유발계수 = L의 열합
- **부가가치유발계수** = v̂L의 열합(v: 부가가치율), **수입유발계수** = A<sup>m</sup>L의 열합. 두 값의 합은 1
- **영향력계수** = L 열합 ÷ 열합 평균(후방연쇄), **감응도계수** = L 행합 ÷ 행합 평균(전방연쇄)
  → Ⅰ(둘 다 ≥1), Ⅱ(감응도만 ≥1), Ⅲ(둘 다 <1), Ⅳ(영향력만 ≥1)로 산업 유형 분류
- **최종수요 항목별 유발효과**: 생산 = LY<sup>d</sup>, 부가가치 = v̂LY<sup>d</sup>, 수입 = A<sup>m</sup>LY<sup>d</sup> + Y<sup>m</sup>.
  생산·부가가치 유발계수는 국산 최종수요로, 수입유발계수는 국산+수입 최종수요로 나눔. 의존도 = 항목별 유발액 ÷ 전체 유발액
- **수요충격**: Δx = LΔf<sup>d</sup>, 직접효과 = Δf<sup>d</sup>, 간접효과 = Δx − Δf<sup>d</sup>, 부가가치 = v̂Δx(피용자보수·영업잉여·고정자본소모·생산세로 분해), 수입 = A<sup>m</sup>Δx (+ 직접 수입).
  `국산+수입 최종수요` 모드는 부문별 최종수요 자급률(국산 최종수요 ÷ 총 최종수요, 재고증감·귀중품 제외)로 국산분만 파급시킴.
  검산: 부가가치유발 + 수입유발 = 입력한 최종수요 변화
- **취업·고용유발**: 취업계수 e<sub>j</sub> = 취업자<sub>j</sub> ÷ 총산출<sub>j</sub>, 취업유발 = êLΔf<sup>d</sup>.
  통계표 16·17의 2023년 대분류별 취업자·임금근로자 수를 쓰므로 **통합대분류에서 정확**하고, 하위 분류에서는 소속 대분류의 취업계수를 같게 적용한 **근사치**(화면에 * 표시)
- **가격파급(레온티에프 가격모형)** p′ = p′A<sup>d</sup> + p<sub>m</sub>′A<sup>m</sup> + v′
  - 수입품 k 가격 r 상승: Δp′ = r·A<sup>m</sup><sub>k·</sub>L
  - 국산품 k 가격 r 외생 상승: Δp<sub>o</sub>′ = r·A<sup>d</sup><sub>k,o</sub>(I − A<sup>d</sup><sub>oo</sub>)<sup>−1</sup>
  - 부가가치 항목 r 상승: Δp′ = r·v<sub>item</sub>′L
  - 소비자물가 영향 = 민간소비지출(국산+수입) 구성비 가중평균, 생산자물가 영향 = 총산출 가중평균
- **보도자료 재현**: 전산업은 33부문을 1부문으로, 농림수산품·공산품·서비스 등은 7부문으로, 소비재제품·생산자서비스 등은 13부문으로 통합한 거래표에서 계산(통계표 각주 "1부문, 7부문, 13부문 등으로 통합하여 작성한 거래표로부터 도출").

일치하지 않는 3개 항목과 이유:
1. 보도자료 `국산 중간투입률 45.2%` — 원자료 정밀값 45.26%. 보도자료가 반올림된 중간투입률(58.8%) − 수입의존도(13.6%)로 표기한 것으로 보임(추정).
2. 통계표 `전산업 취업유발계수 8.163`, `고용유발계수 6.164` — 산식이 공개되지 않아 재현하지 못함(**불확실**). 총취업자 ÷ 국산 최종수요(1부문 통합표)로 계산한 8.205·6.196명은 보도자료 본문의 8.2명·6.2명과 일치.

## 7. GitHub Pages 배포

이 저장소는 `main` 브랜치의 최상위 폴더를 GitHub Pages로 게시합니다. 직접 새 저장소에 올릴 때의 절차는 다음과 같습니다.


1. GitHub에서 `New repository` → 이름 입력, **Public**, `Add README` 켜기 → `Create repository`
2. `Add file → Upload files`로 이 폴더의 **모든 파일과 폴더(data/, docs/, tools/ 포함)**를 압축을 푼 상태로 올리고 `Commit changes`
   - `.nojekyll`은 숨김 파일이라 탐색기에서 안 보일 수 있습니다. 업로드가 안 되면 `Add file → Create new file`로 이름 `.nojekyll`, 내용 없이 만드세요.
3. `Settings → Pages` → Source `Deploy from a branch`, Branch `main`, Folder `/ (root)` → `Save`
4. `Actions` 탭에서 배포 완료를 확인한 뒤 `https://<사용자이름>.github.io/<저장소이름>/`에 접속

## 8. 한계와 유의점

- 산업연관모형은 고정 투입계수, 규모수익불변, 공급 제약 없음, 가격 불변(수량모형)·수요 불변(가격모형)을 가정하므로 결과는 **잠재적 파급효과의 상한**에 가깝습니다.
- 2023년 표는 실측표가 아닌 **연장표**(2020년 실측표 기준 간접 추계)이며 **당해년 가격**이므로, 연도 비교 시 가격 변동을 고려해야 합니다.
- 하위 분류의 취업·고용유발은 대분류 취업계수를 적용한 근사치입니다. 정확한 값은 한국은행 고용표(통합대·중·소분류)가 필요합니다.
- Pyodide는 첫 접속 때 jsDelivr CDN, openpyxl은 PyPI에서 내려받으므로 인터넷 연결이 필요합니다.
